## 🌍 نظرة عامة (Overview)

**Universal CRO & Checkout Funnel Audit** هي مهارة ذكاء اصطناعي وأداة فحص هندسية عالمية مصممة للقضاء التام على الهلوسة والتنظير في تدقيق مسارات الشراء (Checkout Funnels) وتحسين معدلات التحويل (Conversion Rate Optimization).

تعمل المهارة على **أي موقع أو متجر إلكتروني أو مسار حجز في العالم**، بغض النظر عن لغة البرمجة أو المنصة أو السوق الجغرافي:
- **مواقع البرمجة الخاصة (Custom Stacks & Headless):** Next.js, React, Nuxt, Vue, SvelteKit, Laravel, Django, Custom PHP, Node.js, SPAs.
- **المنصات العالمية والمحلية:** Shopify, WooCommerce, Salla (سلة), Zid (زد), Magento / Adobe Commerce, OpenCart, BigCommerce.
- **مسارات التحويل المتنوعة:** متاجر التجزئة (B2C eCommerce)، نماذج جمع بيانات الشركات (B2B Lead Generation)، حجز الاستشارات والعيادات (Appointments)، ومنصات الكورسات والاشتراكات (SaaS).
- **كافة أسواق العالم:** مطابقة حزم الدفع الإلزامية محلياً (السعودية، مصر، الإمارات، الكويت، أمريكا، بريطانيا، هولندا، ألمانيا، بولندا، فرنسا، البرازيل، الهند).

## 🛡️ الركائز الهندسية للمهارة (Core Engineering Pillars)

```
                            🌐 طلب الفحص من العميل
                                       ↓
              [1️⃣ 5-Tier Stealth Engine + Autonomous Cart Seeder]
              ├── المستوى 1: Requests مع تدوير User-Agents وبصمات Sec-CH-UA
              ├── المستوى 2: Googlebot Spoofing لتجاوز جدران WAF
              ├── المستوى 3: Playwright Chromium خفي ومحاكاة الموبايل
              ├── المستوى 4: Real Chrome Off-Screen (-32000px) لحل الكابتشا
              └── المستوى 5: Wayback Machine (Free IP Bypass للحظر التام)
                                       ↓
              [2️⃣ فحص الـ DOM والسمات التفاعلية (Form Ergonomics)]
              ├── إحصاء الحقول ومقارنتها بمعيار Baymard (المثالي 6-8 حقول)
              ├── قياس نسبة امتثال الإكمال التلقائي (Autocomplete Attributes)
              ├── التحقق من فتح لوحة أرقام الموبايل (type="tel" & inputmode="tel")
              ├── كشف تسرب كود الخصم (Open Coupon Box Leaks)
              └── فحص الشراء كزائر (Guest Checkout vs Forced Registration)
                                       ↓
              [3️⃣ محكمة النقد الذاتي وتحدي الفرضيات (Devil's Advocate Court)]
              ├── هل الحقل مطلوب قانونياً في بلد العميل (مثل العنوان الوطني أو CPF)؟
              ├── هل غياب أبل باي حقيقي أم بسبب فحص متصفح ويندوز/لينكس؟
              └── هل التسجيل إجباري فعلياً أم متاح كزائر؟
                                       ↓
              [4️⃣ المحرك الحسابي ومصفوفة العائد المالي (funnel_analyzer.py)]
              ├── معايرة الهبوط الرياضي وفقاً لـ Baymard Meta-Analysis (70.22%)
              └── حساب الإيرادات المفقودة والمستردة شهرياً وسنوياً
                                       ↓
              [5️⃣ تنسيق التسليم المزدوج (Dual Delivery System)]
              ├── مواقع الكود الخاص: أكواد HTML/CSS/JS جاهزة للتنفيذ
              └── المنصات الجاهزة: خطوات بالنقرات من لوحة التحكم (سلة، شوبيفاي، زد)
```

## 🔒 الأقفال الميكانيكية والقواعد الصارمة (Mechanical Locks & Rules)

تحتوي المهارة على **40 قاعدة حرجة** و **17 قفلاً ميكانيكياً حاكماً**، أبرزها:
1. **قاعدة صفر هلوسة (Zero Hallucination):** ممنوع تأليف أي رقم أو نقطة احتكاك؛ الاعتماد حصرياً على مخرجات الاسكريبت أو سكرينشوتات حية.
2. **صلاحية ممتدة مدى الحياة (Lifetime Longevity):** قراءة السنة الحالية ديناميكياً (`datetime.now().year`) وإلزام الـ AI بالبحث الحي لمعايير Baymard لأي عام مستقبلي (2026+).
3. **محكمة النقد الذاتي (LOCK 55 - Devil's Advocate Court):** استجواب الفرضيات للتأكد من صفرية الادعاءات الخاطئة (0% False Positives).
4. **التسليم المزدوج (LOCK 56 - Dual Delivery):** كود نظيف للمطورين، وخطوات لوحة التحكم لأصحاب المتاجر غير التقنيين.
5. **التوثيق بالاقتباس الحرفي (LOCK 57 - Proof-by-Quote):** اقتباس محددات الـ DOM نصياً في كل ملاحظة.
6. **دليل التخطيط العربي (Appendix D):** الخصائص المنطقية للـ CSS (`margin-inline-start`)، إجبار أرقام الهواتف LTR، وأرقام الأسعار المتساوية العرض (`tabular-nums`).

## 🚀 التثبيت والبدء السريع (Quick Start)

### المتطلبات الأساسية
```bash
python -m venv venv

# Windows
venv\Scripts\pip install -r requirements.txt
venv\Scripts\playwright install chromium

# Linux / macOS
./venv/bin/pip install -r requirements.txt
./venv/bin/playwright install chromium
```

### أوامر التشغيل الميدانية (CLI Usage)

```powershell
# 1. فحص مسار الشراء أو صفحة دفع لأي موقع:
$env:PYTHONIOENCODING="utf-8"; py scripts/audit_checkout.py https://example.com/checkout

# 2. الفحص الذكي مع تفعيل السلة آلياً (Auto Add-to-Cart Seeding):
$env:PYTHONIOENCODING="utf-8"; py scripts/audit_checkout.py https://example.com/ --seed-cart

# 3. لمواقع البرمجة الخاصة (React/Next.js/SPA) أو المواقع المحمية بـ Cloudflare:
$env:PYTHONIOENCODING="utf-8"; py scripts/audit_checkout.py https://example.com/checkout --playwright

# 4. محاكاة متصفح الموبايل (iPhone Viewport + Touch Emulation):
$env:PYTHONIOENCODING="utf-8"; py scripts/audit_checkout.py https://example.com/checkout --mobile

# 5. حساب نسبة التسرب المالي والعائد المسترد وتوليد الأكواد:
$env:PYTHONIOENCODING="utf-8"; py scripts/funnel_analyzer.py --fields 12 --autocomplete 4 --guest false --coupon true --traffic 30000 --aov 150
```
